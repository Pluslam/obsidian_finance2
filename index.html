Day 1 · 約 50 分鐘

為什麼一人公司需要第二大腦？安裝與核心概念

🎯 學習目標

  • 明白第二大腦如何解決「多公司財務資料散落」問題
  • 理解 PARA 與 CODE 的基本意思
  • 成功安裝 Obsidian 並建立第一個 Vault

📖 白話解釋

一人公司最痛的地方係：銀行紀錄、發票、收據、報銷、跨公司轉帳全部散落。第二大腦把這些資訊外部化，用系統幫你「提取記憶」。

CODE：Capture → Organize → Distill → Express
PARA：Projects · Areas（財務放呢度）· Resources · Archives
真實攝影感：自然光工作桌，電腦顯示空白 Obsidian，旁邊放銀行月結單與手寫筆記，淺景深

🛠️ 操作步驟

  1. 前往 obsidian.md 下載並安裝
  2. Create new vault，命名為「第二大腦」或「FinanceBrain」
  3. 建立第一個筆記「我的多公司財務第二大腦」
  4. 列出你目前管理的公司名稱

⚠️ 常見錯誤

  • 一開始安裝大量外掛
  • Vault 直接放雲端同步資料夾
  • 想一次把所有舊資料搬進來

✍️ 練習

完成安裝與 Vault。寫下你目前有幾間公司，以及財務上最頭痛的 3 件事。

📌 重點回顧

  • PARA 負責結構，CODE 負責流程

Day 2 · 約 50 分鐘

Markdown 基礎：寫出清晰可讀的財務筆記

🎯 學習目標

  • 掌握標題、列表、粗體、連結等常用語法
  • 能寫出乾淨的交易與對帳筆記

📖 白話解釋

Markdown 係純文字格式，十年後仍然可以打開。財務筆記特別需要清晰結構。

# 大標題　## 小標題　**重要金額**
- 項目　[[另一筆記]]　> 重點摘要

🛠️ 操作步驟

  1. 建立筆記「Markdown 財務練習」
  2. 用標題與列表記錄 2–3 筆虛構交易
  3. 把重要金額用粗體標出
  4. 用 [[ ]] 連結到公司筆記

⚠️ 常見錯誤

  • 標題後面忘記空格
  • 把所有交易塞進一個超長筆記

✍️ 練習

寫一篇「本週重要財務事項」筆記，包含標題、列表、粗體重點，並連結到公司清單。

📝 測驗（單選）

問題：在 Obsidian 建立內部連結的正確寫法是？

📌 重點回顧

  • Markdown 讓筆記長期可讀
  • 財務筆記要短而清晰

雙向連結與 Graph：把公司、交易、專案連起來

🎯 學習目標

  • 熟練使用 [[雙向連結]] 與 Backlinks
  • 理解 Graph View 如何顯示財務關係網絡

📖 白話解釋

一筆交易可能同時關聯「某間公司」、「某個活動專案」、「某張發票」。用連結可以把這些關係永久記錄下來。

真實攝影感：電腦螢幕顯示 Graph View，多個節點連線，旁邊有手寫公司名稱與金額，自然光

🛠️ 操作步驟

  1. 為每間公司建立中心筆記（[[HADO]]、[[Succeed]]）
  2. 建立 2–3 筆交易筆記並用 [[公司名稱]] 連結
  3. 打開 Graph View 觀察連線
  4. 在公司筆記的 Backlinks 查看引用

⚠️ 常見錯誤

  • 連結名稱不統一
  • 忽略 Backlinks 面板

✍️ 練習

建立所有公司的中心筆記，並至少建立 3 筆交易筆記，全部正確連結。打開 Graph View。

📝 測驗（單選）

問題：Backlinks 的主要作用是？

📌 重點回顧

  • 連結讓財務關係可視化
  • 公司中心筆記是重要樞紐
Day 4 · 約 65 分鐘

Capture 與 Organize：PARA 結構 + Properties 入門

🎯 學習目標

  • 建立適合多公司財務的 PARA 資料夾
  • 學會為交易筆記加上 Properties

📖 白話解釋

財務屬於長期責任，主要放在 Areas。

建議財務資料夾（02-Areas/財務）
00-Inbox → 01-交易紀錄 → 02-發票與收據 → 03-銀行對帳 → 04-公司總覽 → 05-每月對帳

Properties 是筆記的元數據。財務最核心欄位：company、type、amount、date、status。

🛠️ 操作步驟

  1. 建立 PARA 四個主要資料夾
  2. 在 02-Areas 建立「財務」及子資料夾
  3. 建立交易筆記，按 Ctrl+; 加入 Properties
  4. 填入 company、type、amount、date、status

⚠️ 常見錯誤

  • Properties 命名不統一
  • Inbox 從不清理

✍️ 練習

完成財務資料夾結構。建立至少 3 筆交易筆記，全部加上統一 Properties。

📝 測驗（單選）

問題：「長期的多公司財務管理」應該放在 PARA 的哪一類？

📌 重點回顧

  • 財務主要放在 Areas
  • Properties 是多公司分類的關鍵
Day 5 · 約 55 分鐘

Distill 與 Express：把交易變成可用的對帳資訊

🎯 學習目標

  • 學會提煉交易筆記的精華
  • 理解 Express 如何應用在財務場景

📖 白話解釋

Distill：在筆記頂部寫一句話總結，用粗體標出關鍵金額與狀態。

Express：從筆記產出「本週待對帳清單」或「某公司現金狀況」。

🛠️ 操作步驟

  1. 選擇一篇交易筆記
  2. 在最上方加一句話總結
  3. 把金額與 status 用粗體標出
  4. 思考可以幫助什麼輸出

⚠️ 常見錯誤

  • 只收集不提煉
  • 從不 Express

✍️ 練習

對至少 2 篇交易筆記完成 Distill，並用其中一篇產出一個小輸出（待對帳清單）。

Day 6 · 約 80 分鐘（重點日）

Bases 儀表板：把交易筆記變成即時財務總覽

🎯 學習目標

  • 明白 Bases 是什麼，以及為什麼特別適合多公司財務
  • 學會建立第一個 Bases 視圖
  • 設計 3–4 個實用財務儀表板

📖 白話解釋：Bases 是什麼？

Bases 係 Obsidian 官方核心插件（2025 年起正式加入）。它可以把「有 Properties 的筆記」變成可篩選、可排序、可直接編輯的資料庫視圖（Table、Cards、List）。

你唔使寫任何程式碼。只要筆記有統一的 Properties，Bases 就能即時顯示「所有待對帳交易」、「按公司分組的現金流」等。

Bases 最大優勢（對一人公司）
• 直接在表格改 status 或 amount，改完即時生效
• 比 Dataview 更快、更穩定、手機也好用
• 一個 Base 檔案可以有多個視圖（待對帳、本月、按公司…）

🛠️ 操作步驟：建立第一個財務 Bases

  1. 設定 → 核心插件 → 開啟 Bases
  2. 在財務資料夾右鍵 → New → Base（或指令面板搜尋 Create new base）
  3. 命名為「財務總覽」或「All Transactions」
  4. 在 Bases 介面加入過濾條件：例如 status = 待對帳
  5. 選擇要顯示的欄位：company、type、amount、date、status、category
  6. 儲存視圖，之後可再新增其他視圖

💡 建議建立的 4 個實用視圖

1. 待對帳交易
過濾：status = 待對帳
排序：date 由新到舊
用途：每日／每週清理清單
2. 按公司分組
分組：company
可顯示各公司收入／支出合計
用途：一眼睇到各業務現金狀況
3. 本月交易
過濾：date 屬於今個月
用途：每月對帳時快速檢查
4. 待收款項目
過濾：type = 收入 且 status = 待收款
用途：追蹤應收帳款

⚠️ 常見錯誤

  • Properties 命名不一致 → Bases 無法正確過濾
  • 忘記開啟核心插件 Bases
  • 建立太多複雜視圖，反而增加維護成本 → 先做 3–4 個最常用就夠
  • 金額欄位不是 number 類型 → 無法正確排序或合計

✍️ 練習

1. 開啟 Bases 核心插件
2. 建立一個名為「財務總覽」的 Base
3. 建立「待對帳交易」視圖（過濾 status = 待對帳）
4. 再建立「按公司分組」視圖
5. 嘗試在表格直接修改一筆交易的 status

📝 測驗（單選）

問題：Bases 最主要的價值是什麼？

📌 重點回顧

  • Bases = 官方無程式碼資料庫視圖
  • 必須先有統一的 Properties 才能發揮作用
  • 建議優先做「待對帳」與「按公司分組」兩個視圖
  • 可直接在表格改狀態，非常適合一人操作

完整實戰專案：多公司財務第二大腦 + Bases 儀表板

🚀 完整實戰專案

請一次完成以下步驟：

  1. 確認 PARA 四個主要資料夾已建立
  2. 在 02-Areas/財務 下建立完整子資料夾
  3. 為每間公司建立中心筆記與「公司總覽」筆記
  4. 建立至少 5 筆真實或模擬交易筆記，全部使用統一 Properties（company、type、amount、date、status、category）
  5. 把交易正確連結到公司與相關專案
  6. 完成至少 2 篇筆記的 Distill
  7. 開啟 Bases 核心插件
  8. 建立「財務總覽」Base，並完成兩個視圖：① 待對帳交易 ② 按公司分組
  9. 建立「每週檢視」模板，並設定固定時間
  10. 用 Bases 實際更新一筆交易的 status
  11. 打開 Graph View，檢視你的財務知識網絡
完成後真實感：電腦螢幕同時顯示 Bases 表格儀表板與 PARA 資料夾，旁邊有手寫對帳清單，自然光，高細節

📅 持續複習計劃

每日：新交易建筆記並加 Properties，或先丟 Inbox
每週：打開「待對帳」Bases 視圖清理、更新 status、檢查跨公司項目
每月：用「本月交易」視圖做完整對帳，更新公司總覽
